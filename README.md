# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are automatically saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with a maximum of 200 characters
- Choose between Personal, Work and Study categories
- View the date and time when each note was created
- Delete individual notes
- Search notes by their text
- Validation for empty and overly long notes
- Automatic note count
- Save notes using localStorage
- Responsive design for smaller screens

## How to Run Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For the best development experience, open the project in Visual Studio Code and use the Live Server extension.
